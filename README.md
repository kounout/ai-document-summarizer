# 📄 AI Document Summarizer

An interactive Python web app built with **Streamlit** and powered by the **Google Gemini API** (`gemini-3.8-flash`). It allows users to quickly generate concise summaries from long articles, papers, or documents.

## 🚀 Features
- Fast text summarization using Google Gemini's latest Flash model.
- Clean UI built with Streamlit.
- Secure environment configuration using `python-dotenv`.
